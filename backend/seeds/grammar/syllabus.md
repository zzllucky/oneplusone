# 初中语法 86223 骨架清单（syllabus）

事实来源：后续所有规则卡、题目、错因解释都按本文件的 `id` 组织。改这里 = 改全局。

## 约定

- **词汇范围**：中考 1600 词内，话题通用，不绑定教材版本。
- **题量**：每个知识点 L1 识别 / L2 变形 / L3 陷阱 各 2 题 = 6 题。
- **深度**：`核心` = 中考高频，必须练熟；`了解` = 初中浅考，题量可减半或只出 L1。
- **学习顺序**：时态 → 语态 → 非谓语 → 实词 → 从句（按依赖排，不按 86223 编号排）。
- **例句**：原创的"教材/真题风格"句，不抄真题原文（版权）。
- 统计：21 模块 / 85 知识点 / 510 题。
