# Feature Specification: 1+1=2（中考英语单词学习测验与错题本）

**Feature Branch**: `001-word-study-quiz`

**Product Name**: **1+1=2**（全站统一展示的产品名称；浏览器标签标题与站内页头均显示该名称）

**Created**: 2026-09-28

**Status**: Draft

**Input**: User description: "面向初中学生的中考英语单词记忆 Web 网站，支持账号体系、自定义每日背词目标；遵循『先完整学习当日单词，再开展测验』流程；具备选择题测验、独立错题本、错题专项复习功能。"

## Clarifications

### Session 2026-09-28

- Q: 中考单词词库的数据从哪里获取？ → A: 内置生成词表 —— 项目内提供中考课标词表数据（约 1600 词：英文 / 中文释义 / 常用短语 / 音标），随系统一同提供，可整体替换，不依赖外部词库服务
- Q: 单词发音从哪里获取（无法提供本地 mp3）？ → A: 在线接口 + 语音兜底 —— 优先调用第三方公共发音接口（如有道 dictvoice 一类公开发音地址）获取音频，无结果 / 失败 / 超时时降级为浏览器语音合成；不要求用户提供任何音频文件
- Q: 部署环境能否访问公网？ → A: 可访问公网 —— 允许发音功能依赖公网第三方接口，公网不可用时按降级路径处理
- Q: 注册能否简化为自由输入账号与用户名？ → A: 可以 —— 注册改为「登录名 + 密码 + 用户名（昵称）」三项自由输入，不再使用邮箱，也不校验邮箱格式
- Q: 登录名允许哪些字符与长度？ → A: 字母 / 数字 / 下划线，3–20 位，不含中文与空格；重名判断与登录匹配均按大小写不敏感处理
- Q: 用户名（昵称）是否要求全局唯一？ → A: 不要求 —— 昵称仅用于页面展示，允许重复，注册时不校验重名
- Q: 密码强度是否随注册简化放宽？ → A: 放宽 —— 由「≥8 位且含字母与数字」改为「≥6 位，不限制字符组合」
- Q: 改完每日目标后，当日已分配的单词集合应如何处理？ → A: 分情况 —— 当日**尚未浏览任何单词**（已浏览数 = 0）时立即按新目标重算当日集合；**已浏览 ≥ 1 个单词**后当日集合保持不变，新目标从次日起生效
- Q: 常用短语的发音按钮做成什么粒度、朗读哪些内容？ → A: 按 `；` 拆成多条短语逐行展示，每条短语一个独立发音按钮，只朗读该短语的**英文部分**（中文释义仅作注释不朗读）；今日学习页与错题本页一致提供；失败时与单词发音同样降级为浏览器语音
- Q: 今日测验的题目顺序要不要与当日学习顺序一致？ → A: 不一致 —— 题目仍覆盖当日全部单词（每词一题），但**题序按本轮测验随机洗牌**（以 attempt 为随机种子，同一轮内顺序固定，中途返回不重排、不漏题），避免"背顺序"代替"背单词"

### Session 2026-09-28（第二轮：品牌命名与多设备访问）

- Q: 产品对外显示的名称用什么？ → A: 统一为 **1+1=2** —— 浏览器标签标题与站内页头标题均显示 "1+1=2"，不再把"中考单词 · 学习与测验"作为产品名展示；"中考英语单词学习测验"仅作为功能描述出现在说明性文字中。
- Q: "手机 / 平板多设备访问"具体包含什么？ → A: 三层含义 —— ① **形态适配**：页面在手机、平板、电脑三种屏幕形态下均可完成全流程，平板（中等宽度）单独满足，并适配触摸操作；② **数据一致**：同一账号在不同设备登录后看到完全一致的每日目标、学习进度与错题本；③ **网络可达**：同一网络内的手机 / 平板可通过网络地址访问该服务，多人多设备可同时使用，不做设备数限制与互踢。
- Q: 是否需要离线访问 / 安装到桌面（PWA）？ → A: 本版不需要 —— 仅通过浏览器访问，不提供离线缓存、添加到主屏幕与原生 App。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 注册登录与访问保护 (Priority: P1)

学生自定义登录名、密码与昵称即可完成注册，之后用「登录名 + 密码」登录；未登录访问站内受限页面时被引导至登录页，登录后回到原目标页。密码在系统内不以明文形式保存。

**Why this priority**: 账号是全部学习数据（进度、每日目标、错题本）的归属依据，没有账号体系其余功能无法对应用户。

**Independent Test**: 新用户注册 → 登出 → 用同一凭据登录成功 → 直接访问今日学习页时被引导至登录页 → 登录后正常进入；单独交付即可作为可用的"个人账号入口"。

**Acceptance Scenarios**:

1. **Given** 一名未注册访客打开注册页, **When** 提交合法的登录名（3–20 位字母 / 数字 / 下划线）、用户名昵称与符合强度要求的密码, **Then** 账号创建成功并进入登录态, 可直接开始当日学习（全程不要求填写邮箱）。
2. **Given** 已注册用户, **When** 提交正确的登录名与密码, **Then** 登录成功并进入首页。
3. **Given** 未登录访客直接访问首页 / 今日学习 / 测验 / 错题本等受限页面, **When** 发起访问, **Then** 被引导至登录页。
4. **Given** 已注册的登录名, **When** 再次用该登录名注册（含仅大小写不同的写法）, **Then** 注册被拒绝并提示该登录名已被使用。
5. **Given** 登录态用户, **When** 提交错误密码, **Then** 登录被拒绝并给出通用失败提示（不泄露账号是否存在）。

### User Story 2 - 设定每日单词目标 (Priority: P1)

学生可在设置页设定"每日单词目标数量"，系统保存该配置，并据此分配当日待学习单词。

**Why this priority**: 每日目标决定当日学习量与测验题量, 是学习节奏的源头配置。

**Independent Test**: 登录 → 设置页把每日目标从默认改为 30 → 保存 → 首页目标数字变为 30；若当日尚未浏览任何单词，学习页立即按 30 个重新分配；若当日已浏览过单词，当日集合不变、次日按 30 分配；单独交付即可作为可用的"个人配置"能力。

**Acceptance Scenarios**:

1. **Given** 已登录用户首次进入设置页, **When** 打开页面, **Then** 显示当前每日目标（未设置时为系统默认值）。
2. **Given** 用户在设置页输入新的目标数量, **When** 保存, **Then** 配置被持久化, 重新登录与跨设备后仍保持该值。
3. **Given** 用户输入超出允许范围或非法格式的目标数量, **When** 保存, **Then** 保存被拒绝并提示允许范围。
4. **Given** 用户当日**尚未浏览任何单词**时修改目标, **When** 再次进入今日学习页, **Then** 当日单词集合立即按新目标重新分配（数量等于新目标, 且不超过词库剩余未学数量）。
5. **Given** 用户当日**已浏览至少 1 个单词**后修改目标, **When** 再次进入今日学习页, **Then** 当日已分配的单词集合与已浏览进度保持不变, 新目标从下一日起生效。

### User Story 3 - 今日单词学习（逐词浏览 + 发音） (Priority: P1)

系统按每日目标自动分配当日待学习单词；学习页逐个展示单词的英文、中文释义与常用短语，并可播放发音；学生浏览完一个单词即标记为【已浏览】，页面显示"已浏览数 / 总数"进度。

**Why this priority**: 这是核心学习动作, 也是测验解锁的前置条件。

**Independent Test**: 登录后进入今日学习页 → 逐个浏览并标记 → 进度递增 → 全部标记完成后测验入口由不可操作变为可操作；单独交付即构成完整学习闭环的第一段。

**Acceptance Scenarios**:

1. **Given** 已登录且已设定每日目标的用户首次进入今日学习页, **When** 页面加载, **Then** 出现数量等于当日目标的今日单词集合, 并且该集合在当日多次进入时保持一致。
2. **Given** 学习页展示某个单词, **When** 用户查看, **Then** 可看到英文单词、中文释义与逐条列出的常用短语, 单词与其每条短语均可独立触发发音播放（短语只朗读英文部分）。
3. **Given** 用户浏览完一个单词, **When** 标记【已浏览】, **Then** 该单词记为已浏览, 页面进度加一并切到下一个未浏览单词。
4. **Given** 当日单词已全部浏览, **When** 返回学习页, **Then** 展示"今日学习已完成"状态。
5. **Given** 第三方发音接口无该单词发音或请求失败, **When** 用户触发发音, **Then** 自动改用浏览器语音播放, 用户仍能听到发音（降级兜底）。

### User Story 4 - 今日单词测验（浏览完成后解锁） (Priority: P1)

仅当日单词全部浏览完成后测验入口才可操作；测验随机给出两种四选一题型（英译中 / 中译英）；答错即把该单词加入错题本，答对只是进入下一题——**不会**移除错题本中该单词的记录；全部题目完成后展示今日测验结果报告。

**Why this priority**: 测验是学习效果验证环节, 也是错题本的唯一"产生"入口, 其解锁规则是本产品的硬性业务流程。

**Independent Test**: 完成当日全部浏览 → 测验入口可点击 → 完成一轮随机题型测验 → 结果报告展示正确率与耗时 → 答错的单词出现在错题本；单独交付即构成"学后即测"闭环。

**Acceptance Scenarios**:

1. **Given** 当日单词未全部浏览, **When** 用户查看测验入口, **Then** 入口不可操作（置灰）并说明需先完成全部浏览；强行直接访问测验页亦被拒绝。
2. **Given** 当日单词全部浏览完成, **When** 用户点击测验入口, **Then** 进入今日测验并开始出题。
3. **Given** 测验进行中, **When** 展示一道题目, **Then** 题目为英译中四选一或中译英四选一（题型随机）, 四个选项中仅一个正确且干扰项来自词库其他单词; 题序为当日全部单词的随机排列（与本轮绑定, 中途返回顺序不变）, 与学习顺序不要求一致。
4. **Given** 用户作答错误, **When** 提交答案, **Then** 系统提示正确答案并把该单词加入该用户错题本（记录加入时间）。
5. **Given** 用户作答正确, **When** 提交答案, **Then** 进入下一题, 且**不**删除错题本中该单词的任何记录（即使错题本中已存在该单词）。
6. **Given** 当日全部题目作答完成, **When** 最后一题提交, **Then** 展示今日测验结果报告（题目数量、答对数量、正确率、用时, 以及本轮新增错题提示）。

### User Story 5 - 错题本列表 (Priority: P1)

错题本汇总该用户所有答错过的单词，列表展示单词信息与"加入错题本时间"，并提供进入错题专项练习的入口；首页同时展示错题总数量。

**Why this priority**: 错题本是学生复习的主入口, 也是专项练习的数据来源。

**Independent Test**: 在测验中故意答错若干单词 → 打开错题本 → 看到这些单词及加入时间 → 首页错题总数与列表一致；单独交付即具备可查阅的错题清单价值。

**Acceptance Scenarios**:

1. **Given** 用户已有错题记录, **When** 打开错题本列表, **Then** 展示全部错题单词及其加入错题本的时间。
2. **Given** 同一单词被多次答错, **When** 查看错题本, **Then** 该单词只保留一条记录, 加入时间保持**首次**答错的时间。
3. **Given** 用户进入首页, **When** 页面加载, **Then** 展示当前错题总数量, 且与错题本列表条数一致。
4. **Given** 日期切换 / 用户重新登录 / 用户学习了新单词 / 今日测验中答对某错题单词, **When** 再次查看错题本, **Then** 错题记录数量与内容均不发生变化。
5. **Given** 错题本为空, **When** 打开列表页, **Then** 展示空状态提示, 专项练习入口不可用并说明原因。

### User Story 6 - 错题专项复习练习（答对方可移除） (Priority: P1)

专项练习只读取当前用户错题本中的单词出题，题型与今日测验一致（英译中 / 中译英随机）；答错保留在错题本，答对则把该单词从错题本**移除**；练习结束输出专项练习报告。

**Why this priority**: 这是错题本中记录的**唯一**移除途径, 承载"错题必须答对才出本"的硬性规则。

**Independent Test**: 错题本中有若干单词 → 进入专项练习 → 答对的单词立刻从错题本消失、答错的仍在 → 结束报告展示答对/答错数量；单独交付即形成错题收敛闭环。

**Acceptance Scenarios**:

1. **Given** 错题本中有若干单词, **When** 进入专项练习, **Then** 题目仅来自该用户错题本, 不包含非错题单词。
2. **Given** 专项练习出了一道题, **When** 查看题目, **Then** 题型为英译中四选一或中译英四选一（随机）, 与今日测验题型形式一致。
3. **Given** 用户在专项练习中作答错误, **When** 提交答案, **Then** 该单词保留在错题本中, 加入时间不变。
4. **Given** 用户在专项练习中作答正确, **When** 提交答案, **Then** 该单词从错题本中移除, 错题总数相应减少。
5. **Given** 专项练习结束, **When** 最后一题提交, **Then** 展示练习报告（练习题目数、答对数、答错数、剩余错题数）。
6. **Given** 某单词在专项练习中被答对移除后又在今日测验中再次答错, **When** 查看错题本, **Then** 该单词重新出现在错题本中, 加入时间为本次答错时间。

### User Story 7 - 手机 / 平板 / 电脑多设备访问 (Priority: P2)

同一套页面在手机、平板与电脑浏览器上均可正常完成注册、学习、测验、错题本与专项练习全流程；中等宽度（平板，含横竖屏）同样可用，触摸操作不会误触；同一账号在任意设备上看到的数据一致；同一网络内的手机 / 平板可通过网络地址直接使用该服务。

**Why this priority**: 初中学生会在家庭电脑、平板与手机之间交替学习, 多设备可用是"随时能背"的前提, 但不改变任何业务规则。

**Independent Test**: 在 360px（手机）、768px（平板）与 1440px（电脑）三种宽度下分别走完"学习 → 测验 → 看错题 → 专项练习"全流程, 各页面均无横向滚动、关键按钮可点击; 再用同一网络内的手机 / 平板通过网络地址登录同一账号, 与电脑端核对每日目标、进度与错题数量完全一致。

**Acceptance Scenarios**:

1. **Given** 用户在手机浏览器（约 360–430px 宽）打开任意页面, **When** 页面渲染, **Then** 内容单列自适应排布, 无需横向拖动即可完成操作。
2. **Given** 用户在平板浏览器（约 768–1024px 宽）打开任意页面, **When** 页面渲染, **Then** 布局在该宽度下同样可用: 导航可达、内容不过度拉伸也不留大片空白; **And When** 平板在横屏与竖屏之间切换, **Then** 页面重排后仍可继续完成当前操作, 已浏览进度与作答进度不丢失。
3. **Given** 用户在电脑浏览器（≥1280px 宽）打开同一页面, **When** 页面渲染, **Then** 内容完整展示且不过度拉伸。
4. **Given** 用户在触摸设备（手机 / 平板）上操作, **When** 点击任一主要按钮（发音、标记已浏览、选项、提交）, **Then** 该按钮的触摸区域足够大（不小于 44×44 CSS 像素）, 连续点击均命中预期目标而不误触相邻元素。
5. **Given** 同一网络内的手机 / 平板通过网络地址打开站点, **When** 用同一账号登录, **Then** 与电脑端看到完全一致的每日目标、当日学习进度与错题本条数。
6. **Given** 多人在各自设备上同时使用, **When** 各自登录自己的账号, **Then** 互不干扰; 同一账号在多台设备同时登录时, **Then** 不被强制下线, 各设备数据以服务端为准保持一致。
7. **Given** 用户打开任意页面, **When** 查看浏览器标签标题与站内页头, **Then** 两处均显示产品名称 "1+1=2"。

### User Story 8 - 单词发音播放与降级 (Priority: P2)

学习页每个单词都可播放发音：优先调用第三方公共发音接口获取该单词音频；接口无结果、请求失败或超时时，自动改用浏览器语音朗读，保证"总能听到发音"。

**Why this priority**: 发音是单词记忆的重要辅助, 但缺失个别音频不应阻断学习流程, 故优先级低于主学习链路。

**Independent Test**: 对"接口能返回发音"与"接口无发音 / 不可用"的单词分别触发发音, 两种情况下均能出声且不报错。

**Acceptance Scenarios**:

1. **Given** 第三方发音接口返回了该单词的音频, **When** 用户点击发音, **Then** 播放该音频。
2. **Given** 第三方发音接口无该单词发音、请求失败或超时, **When** 用户点击发音, **Then** 自动使用浏览器语音朗读该单词。
3. **Given** 第三方发音接口与浏览器语音均不可用, **When** 用户点击发音, **Then** 给出明确提示且不阻断继续学习。

### Edge Cases

- 用户把每日目标**改小**：当日尚未浏览任何单词 → 立即重算为更小的新集合；已浏览 ≥ 1 → 当日集合不变, 新目标下一日生效；不应出现"已浏览数 > 目标数"的错乱状态。
- 用户把每日目标**改大**：当日尚未浏览任何单词 → 立即按新目标补足；已浏览 ≥ 1 → 当日集合不追加, 下一日按新目标分配。
- 目标变更重算当日集合时：已产生的错题本记录 MUST 保持不变, 重算只影响当日待学集合。
- 词库中未学习单词**不足**当日目标数量：按剩余数量分配, 并明确告知用户词库已全部学完（可继续通过错题本复习）。
- 当日单词**跨日未完成**：新的一日重新按目标分配新的单词集合；前一日未浏览完的未完成状态不阻断新一日的学习。
- 用户在测验**中途离开后返回**：当日测验可重新开始, 已产生的错题本记录保留（不会因中断而丢失或被清除）。
- 错题本**为空**时进入专项练习：入口不可用并说明"暂无错题", 不进入空白练习。
- 同一单词在专项练习中被移除后**再次答错**（含同一轮内先答对后改答为错的情况）：重新入本并记录新的加入时间; 一轮内多次作答以**最后一次**为准。
- 测验与专项练习的干扰项：不得出现与正确答案重复或为空的选项。
- 登录名仅大小写不同（如 `Stu01` 与 `stu01`）：视为同一账号, 后者注册被拒, 登录时两种写法均可匹配。
- 昵称与其他用户重复：允许注册与保存, 不做重名提示（昵称非身份标识）。
- 会话失效（长时间未操作）：再次操作被引导至登录页, 登录后回到原页面继续, 学习进度与错题本不受影响。
- 第三方发音接口超时、返回异常或无该单词发音：自动降级为浏览器语音朗读, 不报错、不阻断学习。
- 常用短语**缺少英文部分**或英文部分过长（超出发音接口可处理长度）：该条短语视为不可发音, 按钮不可用或降级为浏览器语音, 不报错。
- 部署环境公网中断：所有单词均走浏览器语音合成, 学习 / 测验 / 错题本功能保持可用。
- 平板**横竖屏切换或分屏**：布局重排后关键按钮仍可点击, 当前浏览进度与已作答进度不丢失、不重复出题。
- 手机窄屏**软键盘弹出**（注册 / 登录 / 设置页）：提交按钮与错误提示仍可见可达, 不被键盘遮挡至无法操作。
- 触摸设备**无悬停**：对错反馈、正确答案、已浏览状态等信息不依赖悬停展示, 否则触摸用户将看不到结果。
- 触摸设备**自动播放限制**：发音必须由用户点击触发; 设备不支持语音合成时给出明确提示而非无声失败。
- 同一账号在**两台设备同时学习**：当日单词集合与已浏览进度以服务端数据为准, 两设备看到一致结果, 不产生重复分配或进度回退。
- 手机 / 平板通过**网络地址**访问：页面资源与接口请求指向同一服务地址, 不出现因访问地址不一致导致的登录态丢失。
- 关键操作（标记已浏览、提交答案）MUST 为单击完成, 不依赖双击或长按, 避免触摸误操作。

## Requirements *(mandatory)*

### Functional Requirements

**账号系统**

- **FR-001**: System MUST 允许用户使用「登录名 + 密码 + 用户名（昵称）」完成注册, 且 MUST NOT 要求或校验邮箱: 登录名 MUST 为 3–20 位的字母 / 数字 / 下划线（不含中文与空格, 重名判断大小写不敏感）, 密码 MUST ≥ 6 位（不限制字符组合）, 昵称 MUST 为 1–24 字符且允许与他人重复。
- **FR-002**: System MUST 拒绝重复登录名注册（仅大小写不同视为同一登录名）并提示该登录名已被使用。
- **FR-003**: System MUST 允许已注册用户使用登录名 + 密码登录（登录名匹配大小写不敏感）, 并在凭据错误时给出不泄露账号是否存在的通用失败提示。
- **FR-004**: System MUST 在访问任何受限页面时校验登录态, 未登录 MUST 引导至登录页。
- **FR-005**: System MUST 以不可逆的加盐哈希方式保存密码, 任何情况下 MUST NOT 保存或输出明文密码。
- **FR-006**: System MUST 提供退出登录能力, 退出后所有受限页面回到未登录状态。

**基础设置**

- **FR-007**: System MUST 允许用户在设置页设置每日单词目标数量, 并限制为 1–200 之间的整数。
- **FR-008**: System MUST 持久化保存用户配置, 重新登录与跨设备访问后保持一致。
- **FR-009**: System MUST 为未设置目标的用户提供默认每日目标数量（默认 20）, 并在设置页显示当前值。
- **FR-010**: System MUST 在当日已浏览至少 1 个单词后保持当日单词集合与浏览进度不变, 目标变更从下一日起生效; 当日尚未浏览任何单词时, 目标变更 MUST 立即按新目标重算当日集合（受词库剩余未学数量限制）。

**单词库**

- **FR-011**: System MUST 内置义务教育中考课标必会单词词库（约 1600 词规模, 以内置词表数据形式随系统一同提供, 不依赖外部词库服务）, 覆盖面向初中学生的备考范围; 词表 MUST 可整体替换或补充, 且替换词表 MUST NOT 影响已有用户的学习进度与错题本。
- **FR-012**: System MUST 为每条单词保存英文单词、中文释义、例句, 以及可选的音标信息。
- **FR-013**: System MUST 为每个用户记录每个单词的学习状态（未学习 / 已学习）, 作为当日分配的依据。

**今日单词学习**

- **FR-014**: System MUST 在用户首次进入今日学习页时, 按当前每日目标数量从未学习单词中分配当日单词集合, 并在当日保持该集合稳定。
- **FR-015**: System MUST 在学习页与错题本页逐词展示英文单词、中文释义与例句; 例句 MUST 按 `；` 拆分为多条逐行展示, 每条例句 MUST 提供独立的发音按钮, 且发音只朗读该例句的**英文部分**（中文翻译仅作为注释展示, 不参与朗读）。
- **FR-016**: System MUST 提供单词发音播放功能: 优先调用第三方公共发音接口获取该单词音频; 接口无结果、请求失败或超时时 MUST 自动降级为浏览器语音合成朗读; 两种路径均 MUST NOT 阻断学习流程。短语发音 MUST 复用同一链路与同样的降级规则。
- **FR-017**: System MUST 允许用户把单词标记为【已浏览】, 并累计展示"已浏览数 / 总数"进度。
- **FR-018**: System MUST 在当日单词**未全部浏览**时保持测验入口不可操作（置灰）, 并阻止通过直接访问地址进入测验。
- **FR-019**: System MUST 在当日单词全部浏览完成后解锁测验入口。
- **FR-020**: System MUST 在词库剩余未学单词不足当日目标时按剩余数量分配, 并明确提示词库已学完。

**今日单词测验**

- **FR-021**: System MUST 仅允许在测验已解锁时进入今日测验。
- **FR-022**: System MUST 提供题型 A：展示英文单词, 4 个中文选项, 选出正确中文释义。
- **FR-023**: System MUST 提供题型 B：展示中文释义, 4 个英文选项, 选出正确英文单词。
- **FR-024**: System MUST 在每题随机选择题型 A 或题型 B, 且四个选项中 MUST 恰好一个正确、干扰项取自词库中其他单词。
- **FR-025**: System MUST 在用户作答错误时把该单词加入该用户错题本, 并记录加入时间。
- **FR-026**: System MUST NOT 因今日测验作答正确而删除错题本中该单词的记录（硬性约束）。
- **FR-027**: System MUST 在作答后给出对错反馈与正确答案, 再进入下一题。
- **FR-028**: System MUST 在全部题目完成后展示今日测验结果报告, 至少包含题目数量、答对数量、正确率、用时, 以及本轮新增错题情况。

**错题本**

- **FR-029**: System MUST 为每位用户维护独立错题本, 展示全部错题单词及其加入错题本的时间。
- **FR-030**: System MUST 保证同一单词在同一用户错题本中只存在一条记录, 加入时间为首次答错时间。
- **FR-031**: System MUST NOT 因日期切换、重新登录、学习新单词或今日测验答对而移除错题记录; 唯一移除条件是错题专项练习中作答正确。
- **FR-032**: System MUST 在首页展示用户错题总数量, 且与错题本列表条数一致。
- **FR-033**: System MUST 在错题本为空时展示空状态, 并将专项练习入口置为不可用并说明原因。
- **FR-034**: System MUST 在错题本列表页提供进入错题专项复习练习的入口。

**错题专项复习练习**

- **FR-035**: System MUST 仅使用当前用户错题本中的单词作为专项练习题目来源。
- **FR-036**: System MUST 使专项练习题型与今日测验保持一致（英译中四选一 / 中译英四选一随机）。
- **FR-037**: System MUST 在专项练习作答错误时保留该单词在错题本中, 且不改变其加入时间。
- **FR-038**: System MUST 在专项练习作答正确时把该单词从错题本中移除。
- **FR-039**: System MUST 在专项练习结束时输出练习报告, 至少包含练习题目数、答对数、答错数、剩余错题数。

**页面与非功能**

- **FR-040**: System MUST 提供 8 个页面: 注册页、登录页、首页、设置页、今日单词学习页、今日单词测验页、错题本列表页、错题专项练习页。
- **FR-041**: System MUST 在首页展示用户信息（用户名昵称）、今日学习进度、每日目标数量与错题总数量。
- **FR-042**: System MUST 支持手机、平板与电脑浏览器自适应访问: 在约 360–430px（手机）、768–1024px（平板）与 ≥1280px（电脑）三档宽度下 MUST NOT 出现需要横向拖动才能完成操作的内容; 平板宽度下 MUST NOT 出现内容过度拉伸或大片留白, 且横屏与竖屏切换后 MUST 仍可完成全部操作。
- **FR-043**: System MUST 把用户、配置、学习进度、测验结果与错题本数据持久化存储在自有服务器数据库中, 服务重启后数据不丢失。
- **FR-044**: System MUST 在浏览器标签标题与站内页头统一展示产品名称 "1+1=2", 全站一致, 且 MUST NOT 再把功能描述（如"中考单词 · 学习与测验"）当作产品名称展示。
- **FR-045**: System MUST 保证主要可点击元素（发音、标记已浏览、选项、提交、导航）在触摸设备上的可触摸区域不小于 44×44 CSS 像素, 且相邻可点元素间距足以避免误触。
- **FR-046**: System MUST NOT 把悬停（hover）作为关键信息的唯一展示方式（对错反馈、正确答案、已浏览状态 MUST 常驻可见）, 以保证触摸设备无悬停时信息不丢失。
- **FR-047**: System MUST 允许同一账号在任意数量的设备上同时登录使用, MUST NOT 因新设备登录而强制下线其他设备; 各设备 MUST 展示完全一致的每日目标、学习进度与错题本数据（以服务端数据为准）。
- **FR-048**: System MUST 可被同一网络内的其他设备（手机 / 平板）通过网络地址访问并完成全部流程, 并在部署说明中给出可访问的网络地址与启用方式。
- **FR-049**: System MUST 在触摸设备上由用户手势（点击发音按钮）触发发音, 且 MUST NOT 因设备限制静默失败而不给用户反馈。

### Key Entities

- **用户（User）**: 使用登录名注册的学生账号, 拥有登录名（唯一）、用户名昵称（可重复, 仅展示）、登录凭据（不以明文保存）、个人配置与学习数据；是进度与错题本的归属主体, 不保存邮箱。
- **单词（Word）**: 中考课标必会单词词条, 包含英文单词、中文释义、例句（每条含英文句子与中文翻译）与可选音标; 单词与例句均可独立发音, 发音按文本从第三方公共发音接口实时获取（例句只取英文部分）, 系统不要求预置本地音频文件。
- **用户配置（UserSetting）**: 用户设定的每日单词目标数量等个性化参数。
- **每日学习任务（DailyStudySet）**: 某一日分配给某用户的单词集合及其浏览进度（已浏览 / 总数）与解锁状态（学习完成 → 测验解锁）。
- **学习记录（WordStudyRecord）**: 某用户对某单词的学习状态与浏览时间, 决定该单词是否再次进入每日分配。
- **错题记录（WrongWord）**: 某用户答错过的单词条目, 记录首次加入时间; 仅能由专项练习答对移除。
- **测验 / 练习记录（QuizAttempt）**: 一次今日测验或专项练习的过程与结果（题目、作答、对错、用时、报告数据）。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 新用户从打开注册页到进入今日单词学习页的全过程可在 2 分钟内完成。
- **SC-002**: 当日单词未全部浏览时, 100% 的测验尝试（点击入口或直接访问地址）均被阻止。
- **SC-003**: 今日测验答对后, 错题本中对应单词记录保留率为 100%; 专项练习答对后, 该单词在错题本中的移除率为 100%。
- **SC-004**: 经历日期切换、重新登录、学习新单词三种操作后, 用户错题本记录数量变化均为 0 条。
- **SC-005**: 在 360px、768px 与 1440px 三种视口宽度下, 用户均可不横向拖动完成"学习 → 测验 → 错题本 → 专项练习"全流程。
- **SC-006**: 单词发音触发后, 第三方发音接口有结果时 100% 播放该音频; 接口无结果或不可用时 100% 自动降级为浏览器语音, 且不出现错误页面。
- **SC-007**: 每日目标为 20 词时, 用户完成当日全部浏览 + 一轮测验可在 10 分钟内完成。
- **SC-008**: 服务重启或用户次日回访后, 账户、每日目标、学习进度与错题本数据保持一致, 数据丢失率为 0。
- **SC-009**: 同一账号在电脑与手机（或平板）两台设备上登录后, 每日目标数值、当日已浏览数与错题本条数的差异均为 0。
- **SC-010**: 同一网络内的手机 / 平板通过网络地址打开站点后, 可在 1 分钟内完成登录并开始学习; 浏览器标签标题与站内页头均显示 "1+1=2"。
- **SC-011**: 触摸设备上主要操作按钮连续点击 20 次, 误触相邻元素的次数为 0（每个按钮可触摸区域不小于 44×44 CSS 像素）。

## Assumptions

- 用户角色仅"普通注册用户（学生）", 本版不含教师 / 家长 / 管理员角色与后台管理界面。
- 词库为随系统内置的义务教育中考课标必会单词表（约 1600 词: 英文 / 中文释义 / 常用短语 / 音标）, 首次交付后需人工抽检释义与短语质量; 后续可用权威词表整体替换且不影响用户数据; 本版不提供用户自定义导入词库。
- 注册**不收集邮箱**, 也不做邮箱验证 / 手机号验证 / 实名验证; 登录名即登录标识（大小写不敏感）, 昵称仅用于展示且允许重复; 因此本版不含"忘记密码"等依赖邮箱找回的流程。
- 本版不含"忘记密码 / 找回密码"流程, 也不含第三方账号登录。
- 每日单词只从**未学习过**的单词中按固定顺序分配, 已学习过的单词不会重复进入每日分配（复习需求由错题本承担）。
- 当日单词集合在首次需要时（访问首页或今日学习页）生成; 只要当日已浏览数为 0, 修改每日目标就会立即重算该集合, 已浏览过单词后当日集合即固定。
- "当日"以服务端统一时区（中国标准时间, UTC+8）划分, 不按用户设备时区个性化; 若需个性化时区将另行确认。
- 今日测验题目覆盖当日全部单词, 每个单词一道题, 题序按本轮测验随机排列（同一轮内固定）; 专项练习默认练习当前错题本中的全部错题（按错题本原有顺序出题）, 用户中途结束即按已作答题目生成报告。
- 测验与专项练习在作答后立即给出对错反馈与正确答案, 不做"全部答完再统一批改"。
- 发音依赖公网可访问的第三方公共发音接口, 本版不采购商业 TTS 服务, 也不要求用户自备音频文件; 接口不可用或单词无发音结果时由浏览器语音合成兜底, 属预期降级路径。
- 部署环境可访问公网; 若后续改为内网 / 离线部署, 发音将全部走浏览器语音合成, 其余功能不受影响。
- 同一账号可在多个设备登录, 本版不做设备数限制与互踢。
- 产品名称统一为 **1+1=2**, 用于浏览器标签标题与站内页头; "中考英语单词学习测验与错题本"仅作为功能描述出现在文档与说明文字中。
- 多设备访问 = "同账号跨设备数据一致" + "同一网络内设备可通过网络地址访问"; 本版不做公网部署、域名绑定与 HTTPS 证书, 也未提供远程访问内网的方式（如需校外访问需另行方案）。
- 本版不做离线访问、添加到主屏幕与原生 App; 页面刷新需要网络可达服务。
- 平板适配以"中等宽度（约 768–1024px）+ 横竖屏切换"为验收口径, 不针对单一机型做定制; 触摸操作口径为"按钮可触摸区域 ≥ 44×44 CSS 像素"。
- 触摸设备上发音由用户手势（点击）触发; 设备不支持语音合成时给出明确提示而不是静默失败。
