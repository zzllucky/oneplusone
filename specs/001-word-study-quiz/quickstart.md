# Quickstart: 中考英语单词学习测验与错题本

**Feature**: 001-word-study-quiz | **Date**: 2026-09-28
**用途**: 端到端验证指南（跑通即证明功能可用）。实现细节见 `data-model.md`、`contracts/api.md` 与后续 `tasks.md`。

## Prerequisites

- Python 3.12+（后端）、Node 20+（前端构建）
- 可选：Docker + Docker Compose（一键启动）
- 公网可访问（单词发音代理需要；不可访问时发音自动降级）

## Setup

```bash
# 方式一：Docker Compose（推荐）
docker compose up --build      # 访问 http://localhost:8000

# 方式二：本地开发
cd backend && python -m venv .venv && .venv/Scripts/activate   # Windows
pip install -e ".[dev]"
alembic upgrade head            # 建表 + 导入约 1600 词种子
uvicorn app.main:app --reload --port 8000

cd frontend && npm install && npm run dev    # http://localhost:5173
```

## Test Commands

```bash
cd backend && pytest -q                 # 单元 + 契约 + 集成
cd frontend && npm run test             # Vitest 组件/交互
```

| # | 步骤 | 预期 |

## 场景 B：每日单词目标

| # | 步骤 | 预期 |
|---|---|---|
| B1 | 首次打开设置页 | 显示默认目标 20 |
| B2 | 改为 30 并保存，刷新 / 重新登录 | 仍显示 30 |
| B3 | 输入 0 或 300 | 保存被拒并提示允许范围 1–200 |

| B5 | 当日**一个单词都没浏览**时把目标改为 8 | 首页与学习页的今日数量**立即**变为 8（再改为 3 则立即变 3） |

## 场景 C：今日单词学习与发音

| # | 步骤 | 预期 |

对应：FR-014 ~ FR-017；US3 / US8；SC-006

## 场景 E：今日测验与错题入本

| # | 步骤 | 预期 |

## 场景 H：响应式与数据持久化

| # | 步骤 | 预期 |
|---|---|---|
| H1 | 在 360px（手机）、768px（平板）、1440px（桌面）宽度下走完"学习 → 测验 → 错题本 → 专项练习" | 各页面均无需横向拖动即可完成操作 |
| H1b | 平板宽度下横屏 / 竖屏切换后继续当前操作 | 布局重排仍可用，已浏览与已作答进度不丢失 |
