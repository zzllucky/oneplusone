# Feature Specification: 初中英语语法学习（大纲 · 学卡 · 练习）

**Feature Branch**: `006-grammar-study`

**Created**: 2026-10-19

**Status**: Draft

**Input**: User description: "在单词学习之外增加语法学习模块：按中考考点的语法大纲浏览知识点，逐点看学卡（先猜后讲、学后检测），再做题库练习（分层出题、即时判分、错因解析），答错的知识点回链到语法错题本并可直达对应学卡重学。"

## Clarifications

### Session 2026-10-19

- Q: 语法内容从哪来？ → A: 内置教研内容 —— 项目内提供初中语法大纲（21 模块 / 85 知识点）与配套学习卡、题库，随系统一同提供，不依赖外部内容服务。
- Q: 大纲按什么粒度展示？ → A: 按模块分组的知识点列表 —— 一屏可看到全部模块与每个知识点的标题、考点深度（核心 / 了解）与当前掌握状态，不做分页、不做搜索。
- Q: 一个知识点的学习流程是什么？ → A: 三段式 —— ① 猜一猜（先给例句抛出问题，选完立即给回调反馈）② 讲解（规则 / 对比 / 速记三种卡面之一，含信号词、公式、锚例句、易错陷阱）③ 学后检测（卡内 3 题，做完判分）。
- Q: "掌握"如何判定？ → A: 学后检测全部答对即标记为已掌握；未全对或只看不测标记为学习中。练习答对不提升掌握状态，练习答错也不降低掌握状态，只影响语法错题本。
- Q: 练习的题目从哪来、怎么排序？ → A: 该知识点专属题库，按 L1 识别 → L2 变形 → L3 陷阱 递进顺序出题，不做随机洗牌（递进本身就是设计意图）。
- Q: 答错后怎么回链？ → A: 知识点级回链 —— 每道题带错误标签（指向知识点），答错即把该知识点记入语法错题本；错题本条目可直接跳回对应学卡重学。
- Q: 语法错题怎么移除？ → A: 连续答对移除 —— 与单词错题本同一规则：该知识点连续答对达到阈值（2 次）后移出语法错题本，答错则连续数归零。
- Q: 是否需要发音 / 音频？ → A: 不需要 —— 语法学习以文本阅读与选择作答为主，例句不提供朗读。
- Q: 与单词学习的关系？ → A: 并列的两个学习板块 —— 语法有独立入口与独立进度，不与每日背词目标、今日测验、单词错题本互相影响。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 浏览语法大纲并看到进度 (Priority: P1)

学生从导航进入语法板块，看到按模块（8 大时态 / 2 大语态 / 2 大非谓语 / 6 大实词 / 3 大从句）分组的全部知识点列表，每个知识点标注考点深度（核心 / 了解）与自己的状态（未学 / 学习中 / 已掌握 / 有错题），顶部给出"已掌握 / 全部"的计数。点击任一知识点进入该点学卡。

**Why this priority**: 大纲是语法板块的主入口与导航骨架，没有它学生无法定位到具体知识点，后续学卡与练习均无从进入。

**Independent Test**: 登录后进入语法页 → 看到全部模块与知识点、状态默认为未学、顶部计数为 0 已掌握 → 单独交付即可作为可浏览的"语法地图"。

**Acceptance Scenarios**:

1. **Given** 已登录且从未学过语法的学生, **When** 打开语法大纲页, **Then** 看到 21 个模块分组下的全部知识点，每个知识点显示标题与深度标签，状态均为"未学"。
2. **Given** 学生已掌握若干知识点, **When** 打开语法大纲页, **Then** 这些知识点显示"已掌握"标记，顶部"已掌握 / 全部"计数与实际一致。
3. **Given** 学生在练习中答错过某个知识点, **When** 打开语法大纲页, **Then** 该知识点除掌握状态外还显示"有错题"标记，并可一键跳到语法错题本。
4. **Given** 学生在窄屏（手机）打开语法大纲页, **When** 浏览列表, **Then** 模块与条目纵向排布、不出现横向滚动，点击区域满足触摸操作。

### User Story 2 - 看学卡完成一次学习（猜一猜 → 讲解 → 学后检测） (Priority: P1)

学生点开一个知识点，先看"猜一猜"：两个例句加一个选择题，选完立刻给出针对性回调反馈（不论对错都解释为什么）；再看讲解卡面（规则型 / 对比型 / 速记型之一，含信号词、公式、锚例句与易错陷阱对照）；最后做卡内检测（3 题），逐题判分并给出解析与错因，做完给出本轮结果与掌握判定。

**Why this priority**: 学卡是学生真正"学会"一个知识点的环节，是语法板块的价值核心。

**Independent Test**: 进入任一未学知识点 → 完成猜一猜 → 阅读讲解 → 做完 3 道检测题 → 看到结果与状态变化；单独交付即可作为可用的"学一个语法点"能力。

**Acceptance Scenarios**:

1. **Given** 学生打开一个未学知识点的学卡, **When** 在"猜一猜"中任选一个选项, **Then** 立即看到针对所选选项的解释性反馈，随后可进入讲解。
2. **Given** 学生阅读讲解卡面, **When** 卡面为规则型, **Then** 看到规则说明、信号词、变化公式、带注释的锚例句与"错句 / 正句 / 原因"的陷阱对照；为对比型时看到对比表；为速记型时看到记忆口诀。
3. **Given** 学生完成讲解进入学后检测, **When** 提交某一题的答案, **Then** 立即得知对错、正确选项、解析；答错时额外看到所选错项的错因说明。
4. **Given** 学生做完卡内检测且全部答对, **When** 本轮结束, **Then** 该知识点状态变为"已掌握"，大纲页计数同步更新。
5. **Given** 学生做完卡内检测但未全对, **When** 本轮结束, **Then** 该知识点状态为"学习中"，不会标记为已掌握。
6. **Given** 学生只看了讲解未做检测就离开, **When** 返回大纲页, **Then** 该知识点状态为"学习中"（已学但未测），不标记为已掌握。

### User Story 3 - 做题库练习并即时判分 (Priority: P2)

学生针对某个知识点发起题库练习，系统按 L1 识别 → L2 变形 → L3 陷阱的递进顺序给出该点题库题目，逐题作答即时判分（对错、正确项、解析、错因），结束后给出本轮正确率与用时，并可在练习中途随时结束。

**Why this priority**: 练习是把"看懂"变成"会用"的环节，也是错题产生的主要来源；依赖学卡（US2）先建立认知。

**Independent Test**: 进入一个已有题库的知识点 → 发起练习 → 逐题作答看到判分与解析 → 结束看到正确率；单独交付即可作为可用的"练一个语法点"能力。

**Acceptance Scenarios**:

1. **Given** 学生在一个含题库题目的知识点发起练习, **When** 练习开始, **Then** 按 L1 → L2 → L3 的顺序拿到该知识点的题目，每题含四个选项。
2. **Given** 学生正在练习, **When** 提交某题答案, **Then** 立即看到对错、正确选项与解析；答错时看到所选选项的错因说明。
3. **Given** 学生做完本轮全部题目, **When** 结算, **Then** 看到总题数、答对数、答错数、正确率与用时。
4. **Given** 学生中途退出练习, **When** 再次发起该知识点的练习, **Then** 可以重新开始一轮（不恢复上一轮未答题目）。
5. **Given** 某知识点只有卡内检测题、没有题库题, **When** 学生尝试发起练习, **Then** 系统明确提示该知识点暂无练习题，不给出空练习。
6. **Given** 学生未看过学卡就直接在某知识点发起练习（Alternate）, **When** 练习开始并结算, **Then** 可正常练习与判分，但该知识点掌握状态保持原状（未学仍为未学），练习不产生掌握判定。
7. **Given** 学生重复打开一个"已掌握"的知识点并再次做学后检测（Alternate）, **When** 本轮未全对, **Then** 状态仍为"已掌握"，不降级为学习中。
8. **Given** 学生已有未完成的练习轮次, **When** 再次发起同一知识点的练习, **Then** 新建一轮并从第一题开始；旧轮次保留为"未完成"，不参与任何统计与展示。

### User Story 4 - 语法错题本与回链重学 (Priority: P2)

学生练习中答错的知识点自动进入语法错题本；错题本按加入时间列出知识点，显示累计答错次数与当前连续答对次数，并可直接跳回该知识点学卡重学；该知识点连续答对达到阈值后自动移出错题本，答错则连续数归零。

**Why this priority**: 错题回链决定学生能否"错了之后知道回去补哪里"，是语法学习的闭环；依赖练习（US3）产生错题。

**Independent Test**: 练习中故意答错 → 语法错题本出现该知识点 → 从错题本跳回学卡重学 → 再练并连续答对达标 → 该知识点移出错题本；单独交付即可作为可用的"语法错题闭环"。

**Acceptance Scenarios**:

1. **Given** 学生在练习中答错某题, **When** 判分返回, **Then** 该题所属知识点被记入语法错题本（已在其中则累计次数加一、连续答对数归零）。
2. **Given** 语法错题本中存在某知识点, **When** 学生点击该条目, **Then** 直达该知识点的学卡页可重新学习。
3. **Given** 错题本中的知识点在后续练习中被连续答对达到阈值, **When** 达到阈值那一题判分完成, **Then** 该知识点自动移出语法错题本。
4. **Given** 错题本中的知识点在连续答对过程中又答错一次, **When** 判分完成, **Then** 连续答对次数归零，仍需重新累计达标才移出。
5. **Given** 学生在学后检测中答错, **When** 判分完成, **Then** 同样把该知识点记入语法错题本（学后检测与练习共用同一错题回链规则）。

---

### Edge Cases

- 知识点只有卡内检测题（无题库题）时，练习入口不可用并给出明确提示，不产生空轮次。
- 同一道题在一次练习中被重复提交：以首次作答结果为准，不重复计分、不重复累加错题次数。
- 对已结束的练习重复结算：拒绝并提示该轮已结束，统计数字不被篡改。
- 提交不属于该题的选项标识：拒绝并提示参数不合法。
- 学生切换账号或换设备登录：语法进度、掌握状态与语法错题本随账号一致，不随设备变化。
- 语法错题本为空时：显示空状态引导，不报错。
- 学后检测与练习同时进行互不干扰：两者是各自独立的轮次，统计分别计算。
- 多端同时学习同一知识点：各自轮次独立判分与结算，掌握状态以各轮结算结果为准（后一次结算覆盖前一次）；不做跨轮合并，也不提示冲突。
- 知识点内容后续更新（合并卡覆盖范围调整、题量增减）：既有学习记录按知识点标识保留，不因内容更新而清空；标识被移除的记录在库中保留但不展示。首版不做记录迁移与合并。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 提供按模块分组的语法大纲，展示全部知识点及其考点深度（核心 / 了解）。
- **FR-002**: 系统 MUST 为每个知识点保存并展示该学生的掌握状态（未学 / 学习中 / 已掌握）与是否仍有错题。
- **FR-003**: 系统 MUST 提供大纲级的汇总计数（已掌握数 / 知识点总数 / 错题知识点数）。计数口径为**学习卡**：当前 82 张卡覆盖 85 个大纲考点，合并卡按一张卡计一个条目，进度与掌握状态均以卡为单位。
- **FR-004**: 系统 MUST 提供知识点学卡内容，包含"猜一猜"（例句 + 问题 + 选项 + 选择后的解释性反馈）与讲解卡面（规则型含信号词 / 公式 / 锚例句 / 陷阱对照，对比型含对比表，速记型含记忆口诀）。
- **FR-005**: 系统 MUST 提供每个知识点的学后检测（卡内题目），逐题判分并返回正确选项、解析，答错时返回所选错项的错因说明。
- **FR-006**: 系统 MUST 在学后检测全部答对时把该知识点标记为已掌握；未全对或仅浏览未检测时保持为学习中。掌握状态一经达成即保持：已掌握的知识点再次检测未全对时**不降级**；题库练习的任何结果都不改变掌握状态（既不提升也不降低）。
- **FR-007**: 系统 MUST 在题目被作答前不向客户端泄露正确选项与错因说明。
- **FR-008**: 系统 MUST 提供知识点题库练习，按 L1 识别 → L2 变形 → L3 陷阱 的递进顺序出题，不做随机洗牌。三层的含义固定为：
  - **L1 识别**：读句后直接选出正确形式（四选一，规则在句中可见），用于"认得出"。
  - **L2 变形**：给出提示词（如括号内原形或中文提示）要求选出变化后的正确形式，覆盖不规则变化与特殊拼写。
  - **L3 陷阱**：含典型易错干扰项的语境辨析、找错句或上下文限定下的选择，干扰项必须来自该考点的常见误用。
- **FR-009**: 系统 MUST 对练习逐题即时判分，返回对错、正确选项与解析，答错时返回所选错项的错因说明。
- **FR-010**: 系统 MUST 在练习结束时给出本轮总题数、答对数、答错数、正确率与用时。
- **FR-011**: 知识点无题库题时，系统 MUST 拒绝发起练习并给出明确提示。
- **FR-012**: 系统 MUST 在答错（学后检测或练习）时把题目所属知识点记入该学生的语法错题本，已存在则累计答错次数并把连续答对次数归零。
- **FR-013**: 系统 MUST 在知识点连续答对达到阈值（2 次）时把它移出语法错题本。
- **FR-014**: 系统 MUST 提供语法错题本列表（知识点标题、所属模块、累计答错次数、当前连续答对次数、加入时间），并支持从条目直达该知识点学卡。
- **FR-015**: 系统 MUST 保证同一轮内同一道题的重复作答不重复计分、不重复累加错题次数。
- **FR-016**: 系统 MUST 拒绝已结束轮次的再次作答或再次结算。
- **FR-017**: 系统 MUST 拒绝不属于该题目的选项标识并提示参数不合法。
- **FR-018**: 所有语法接口 MUST 要求登录态，未登录一律拒绝并引导登录。
- **FR-019**: 语法学习数据 MUST 与账号绑定，同一账号在不同设备看到完全一致的大纲进度与错题本。
- **FR-020**: 语法板块 MUST 与单词板块相互独立。互不影响的方面逐项列举如下，任一方向都不产生变化：
  - 每日背词目标与今日单词集合（目标设置、今日进度、已浏览标记）
  - 单词测验（解锁条件、题目、结果与测验记录）
  - 单词错题本与其专项练习（唯一移除途径保持不变）
  - 学习统计与总结页数据
  - 反向同理：单词模块的操作也不改变语法进度、掌握状态与语法错题本
- **FR-021**: 语法页面 MUST 在 360 / 768 / 1440 三种视口下完整可用，窄屏不出现横向滚动。
- **FR-022**: 系统 MUST 对练习发起、判分结果、错题本增删输出结构化日志（含用户标识与知识点标识），且不记录任何身份类个人信息。

### Key Entities *(include if feature involves data)*

- **语法知识点（学习卡）**: 一个中考语法考点 = 一张学习卡；属性：标识（如 `G-A01`）、所属模块与模块名、标题、考点深度（核心 / 了解）、卡面类型（规则 / 对比 / 速记）、大纲展示顺序、教研内容（猜一猜 + 讲解）、覆盖的大纲知识点编号集合。
- **语法题**: 归属于一个知识点；属性：题目标识、来源（卡内检测 / 题库练习）、难度层级（L1 / L2 / L3）、题干、解析、错误标签（答错时回链的知识点）、顺序。
- **题目选项**: 归属于一道题；属性：选项键（A–D）、选项文本、是否为正确项、错项的错误原因说明。
- **知识点掌握进度**: 一个学生 × 一个知识点一条；属性：状态（未学 / 学习中 / 已掌握）、检测累计题数与答对数、首次学习时间、掌握时间。
- **练习 / 检测轮次**: 一次学后检测或一次题库练习；属性：知识点、来源、难度层级、总题数、答对数、答错数、开始与结束时间。
- **作答记录**: 一轮中的一题一次作答；属性：所属轮次、题目、所选选项键、是否正确、作答时间；一轮内一题仅一条。
- **语法错题本条目**: 一个学生 × 一个知识点一条；属性：累计答错次数、当前连续答对次数、加入时间、最近答错时间。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 点击次数可客观计量（一次点击 = 一次导航或按钮触发）：首页/底部导航 → 语法大纲 1 次 → 点击知识点进入学卡 2 次。即"进入任一知识点学卡 ≤ 2 次点击"；继续走完一次完整学习（看讲解 → 开始检测 → 3 道检测题各选一项 → 查看结果）再 6 次，全程 ≤ 8 次点击。
- **SC-002**: 大纲页展示全部 21 个模块分组与知识点，且与服务端该账号大纲接口的响应逐点比对：模块分组与顺序、知识点条目数、每个知识点的状态与"有错题"标记、顶部"已掌握 / 全部 / 错题知识点"计数 100% 一致（无错位、无漏项）。
- **SC-003**: 判分接口在本地环境下即时返回（p95 < 300ms），错题本增删与掌握状态在同一请求内完成，不出现"判分成功但状态未更新"。
- **SC-004**: 端到端闭环可验证：练习答错 → 知识点进入错题本 → 从错题本回到学卡重学 → 再练连续答对达标 → 自动移出错题本。
- **SC-005**: 语法板块新增或修改不导致单词板块任何既有行为变化（单词模块全部既有测试保持通过）。
- **SC-006**: 三种视口（360 / 768 / 1440）下语法三个页面均完整可用，无横向滚动、无元素溢出。

## Assumptions

- 复用现有账号体系与登录守卫，语法页面沿用同等访问控制，不新增注册字段、不收集任何新的个人信息（符合章程"最小必要"）。
- 语法大纲以系统内置的知识点学习卡为准（当前 82 张卡覆盖 85 个大纲知识点，合并卡通过"覆盖编号集合"命中多个考点），不额外维护第二份大纲数据源。
- 语法学习不涉及音频、图片等外部资源，不引入新的第三方依赖，也不依赖公网。
- 掌握阈值、错题移除阈值等规则常量集中在服务端，前端不复制业务规则。
- 首版不提供跨知识点的混合练习、练习历史回顾、知识点搜索与错题导出。
