# Quickstart: 词库循环学习与轮次统计

**Feature**: `003-library-cycle-rounds` | **Date**: 2026-09-29

端到端验证指南。前置：本地已能启动后端（默认 `http://localhost:8000`）与前端，且已完成 `003` 迁移（错题熟练度）后新增的 `004` 迁移。

> ⚠️ **请使用新注册（无历史学习记录）的账号验证**：本版不考虑历史账号（research R-005），迁移 `004` 不回填轮次行，已有学习历史的账号升级后的行为不做定义与保证。

## 准备：把账号推到"快学完词库"的状态

词库 2096 词，逐日学完太慢。用两种方式之一造数据：

1. **脚本预置（推荐）**：在临时库里把该账号的 `study_rounds.cursor_word_id` 直接设为接近词库末尾（如 `MAX(words.id) - 20`），并设每日目标为 `20`；
2. **改大每日目标**：设置页把每日目标临时调到允许范围内的最大值，连续学两天。

验证前先确认基线：`GET /home/summary` 的 `completed_rounds` 为 `0`、`current_round.round_no` 为 `1`。

## 场景 A — 词库学完后不再卡死（SC-001）

1. 把账号推进到"词库仅剩少量未学"，学完这些单词并做完当日测验。
2. 把系统日期 / 服务端"当日"推进一天（或改服务器时区口径下的次日），重新打开学习页。
3. **预期**：学习页出现新一轮单词（数量 = 每日目标），不再显示"今日暂无待学习单词"；首页进度不再是 `0 / 0`。

## 场景 B — 新一轮按词库原顺序，每词一次（FR-012 / FR-003 / SC-004）

1. 在新一轮首日观察学习页第一个单词，应为词库 `words` 表中 id 最小的单词。
2. 连续多天推进，记录每天分配到的单词。
3. **预期**：单词按词库原顺序连续推进；在一轮结束前不出现重复单词；一轮结束时覆盖 2096 个不同单词。

## 场景 C — 完成一轮的计数（FR-004 / SC-003）

1. 学到本轮最后一个单词（当日集合覆盖完词库），**先不做测验**，打开首页。
2. **预期**：`completed_rounds` 仍为上一次的数值（不增加）；`current_round.pending_quiz` 为 `true`，页面显示"本轮单词已学完，完成今日测验即可计入第 N 轮"（FR-015）。
3. 完成当日的今日测验（做到最后一题 → 提交）。
4. **预期**：首页显示"已完成 1 轮"，`current_round.round_no` 变为 `2`、`learned_count` 归零后随新一轮推进增长。

## 场景 D — 轮末未做测验的补记（FR-014）

1. 构造"本轮最后一个单词已浏览完，但当天未提交测验"，然后推进到次日，**先打开首页**。
2. **预期**：首页上该轮已被补记为已完成（`completed_rounds` +1）—— 补记发生在轮次读取的统一入口，不必先进学习页（FR-014）。
3. 再打开学习页、刷新页面、换设备/重新登录。
4. **预期**：看到的 `completed_rounds` 与首页**完全一致**；当天不为该生伪造任何测验成绩（测验记录仍为未完成 / 不存在）；学生可直接开始新一轮，不会卡住。

## 场景 E — 跨轮过渡日不混轮（FR-009）

1. 把每日目标设为 `30`，在当前轮只剩 `8` 个单词时进入次日。
2. **预期**：当日集合只有这 `8` 个单词（不提前借新一轮的词凑满 30），学习页提示"本日按剩余数量分配"；再下一日才开始新一轮，且新一轮从词库第一个词开始。

## 场景 F — 跨轮不清历史（FR-008 / SC-005）

1. 跨轮前记录：错题本条数、错题库条数、某历史日期的学习与测验结果。
2. 完成一轮并进入新一轮后再次查看。
3. **预期**：错题本 / 错题库内容与条数完全一致；历史日期的记录仍可查看（后续接入 002 学习日历总结后同样可回溯）。

## 场景 G — 跨设备与重新登录一致（SC-006）

1. 在浏览器 A 学到第 2 轮中途，记录 `completed_rounds` 与本轮进度。
2. 登出后在另一浏览器 / 设备登录同一账号。
3. **预期**：轮数与本轮进度与 A 完全一致。

## 回归（不得被破坏）

- 未完成当日浏览 → 测验仍锁定（`quiz_locked`）。
- 今日测验答错仍进错题本与错题库；专项练习答对仍按既有规则移除错题本条目（答对 1 次不移除，连续答对 2 次才移除）。
- 每日目标修改规则不变（未浏览时立即重算，已浏览次日生效）。
