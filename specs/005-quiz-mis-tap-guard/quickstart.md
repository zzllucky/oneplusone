# Quickstart: 测验防误触验证指南

**Feature**: 005-quiz-mis-tap-guard | **Date**: 2026-10-19

本指南用于端到端验证两个能力：**答题进行中离开需二次确认**、**切题后选项防连点**。契约细节见 [contracts/ui-guard.md](./contracts/ui-guard.md)，状态判定见 [data-model.md](./data-model.md)。

## 前置条件

- 已安装前端依赖：`cd frontend && npm install`
- 后端可启动（用于真实答题）：`cd backend && .venv\Scripts\python.exe -m uvicorn app.main:app --port 8000`
  - 或前端开发态：`cd frontend && npm run dev`（默认 `:5173`，已配置 `/api` 代理）
- 手机验证需与电脑在同一局域网，访问 `http://<电脑局域网IP>:8000`（手机才会出现底部导航）

## 自动化验证

```bash
cd frontend
npm run typecheck     # 类型检查，必须无报错
npm test              # 全部用例通过；含本次新增的弹窗、守卫、锁定与页面级用例
npm run build         # 构建通过（生产形态由后端托管 dist）
```

预期结果：`typecheck` 无输出错误，`test` 全绿且包含以下新用例分组 —— `ConfirmDialog`、`useQuizExitGuard`、三个答题页的离开拦截、`QuizQuestion` 锁定窗口；既有 `quizSound` / `routeSound` / `soundEvents` 用例保持通过。

## 端到端手工验收

### 场景 A：答题进行中离开被拦截（手机底部导航）

1. 登录 → 学习页浏览完当日单词 → 进入测验页，点「开始测验」，答 2 题
2. 点击底部导航任意一项（如「首页」）
3. **预期**：弹出确认弹窗（标题"离开测验？"、正文"离开后本轮测验不会保留，确定离开吗？"），**页面未跳转**
4. 点「继续答题」
5. **预期**：弹窗关闭，仍停在第 3 题，已答进度与对错反馈不变

### 场景 B：确认离开后本轮作废

1. 接场景 A，点底部导航 → 点「离开」
2. **预期**：跳转到所点的页面
3. 再次回到测验页
4. **预期**：呈现未开始状态，需重新点「开始测验」；此前答错的词仍在错题本中

### 场景 C：不打扰既有流程

1. 在测验页**未点开始**时点底部导航 → **预期**：直接跳转，无弹窗
2. 答完全部题目看到结果页后点底部导航 → **预期**：直接跳转，无弹窗
3. 在首页 / 学习 / 错题 / 总结 / 设置页点导航 → **预期**：行为与改动前完全一致，无弹窗

### 场景 D：返回操作同样受保护

1. 答题进行中，使用浏览器返回按钮（手机用返回手势）
2. **预期**：与点导航一致，弹出确认弹窗而非直接离开

### 场景 E：切题防连点

1. 答完一题后，快速在「下一题」位置连点 2–3 次
2. **预期**：不会提交任何答案，无答对 / 答错提示与音效
3. 等待约 0.3 秒后点击一个选项
4. **预期**：正常作答，反馈与音效照常

### 场景 F：三个答题页一致

在**今日测验 / 错题专项 / 错题库专项**三页分别重复场景 A 与场景 E。
**预期**：三页弹窗文案、按钮、锁定表现完全一致。

### 场景 G：桌面形态

浏览器宽度 ≥ 768px 时导航为左侧栏，重复场景 A。
**预期**：侧栏导航点击同样触发确认弹窗（守卫与导航形态无关）。

## 收敛判据

- 场景 A–G 全部符合预期；
- 一轮 20 题人工走查（手机与电脑各一次）中，因误触导致的非预期跳页或误选次数为 0（对应 SC-006）；
- 自动化命令全部通过。
