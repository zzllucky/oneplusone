# Phase 1 Data Model: 测验防误触

**Feature**: 005-quiz-mis-tap-guard | **Date**: 2026-10-19

本次**不新增**服务端实体、字段或迁移；数据层面只复用既有实体，并在前端定义状态判定与一个时间常量。

## 复用实体（服务端既有，本次不改）

| 实体 | 代表什么 | 与本次的关系 |
|---|---|---|
| `QuizAttempt` | 一次答题轮次（`kind` 区分今日测验 / 错题专项 / 错题库专项） | 用于理解"一轮"的边界；判定答题中不查库 |
| `QuizAnswer` | 轮次内每题的作答结果（按 `(attempt_id, word_id)` 唯一） | 「离开」后已提交的记录保留，不删除、不回滚 |

## 前端页面状态（判定"答题中"的依据）

三个答题页（今日测验 / 错题专项 / 错题库专项）状态字段同构：

| 字段 | 含义 | 取值 |
|---|---|---|
| `questions` | 本轮题目列表 | 未开始为空数组；开始后非空 |
| `currentIndex` | 当前题序号 | 0 起 |
| `result` | 当前题的作答结果（含对错与正确项） | 未作答为 `null` |
| `report` | 结果页数据 | 未结束为 `null`；查看结果后非空 |

**判定式**：`答题中 = questions.length > 0 && !report`

## 状态机（页面级）

```text
[未开始] --点击开始--> [答题中] --答完全部并查看结果--> [结果页]
                        |                                  |
                        | 离开（确认后）                     | 离开（直接跳转）
                        v                                  v
                     [未开始]（本轮作废）                  [未开始]
```

- 进入 `[结果页]` 后不再拦截离开；
- 从 `[答题中]` 确认离开后回到 `[未开始]`，需重新点击开始；
- 已产生的作答记录不随状态回退而删除（对应 spec FR-006）。

## 新增常量（前端）

| 常量 | 值 | 说明 |
|---|---|---|
| `QUIZ_OPTION_LOCK_MS` | `300` | 切题后选项锁定窗口（毫秒），spec 允许在 200–500 区间按实测微调，改动需同步契约与测试 |

## 校验规则

- 「答题中」判定不得依赖网络请求或服务端查询，仅由页面状态得出；
- 锁定窗口只在题目发生切换（题目对象或序号变化）时启动，不得在渲染、作答反馈出现时重复启动；
- 锁定窗口内的点击不得产生任何作答数据（`QuizAnswer` 不新增记录）。
